📘 AI Threat Detection System – Full Code & Conceptual Explanation

This document provides a detailed explanation of each step in building an AI model to detect network threats using the UNSW-NB15 dataset.

🔍 Step 1: Load and Clean Data

df = pd.read_csv("UNSW-NB15-processed.csv")
df.drop(columns=['id', 'attack_cat', 'attack_ttp'], inplace=True)
df.drop_duplicates(inplace=True)

Explanation: The dataset is cleaned by removing identifiers and duplicated rows. The focus is on simplifying the input for the model by dropping columns not needed for classification.

✂️ Step 2: Split Features and Target

X = df.drop('label', axis=1)
y = df['label']

Explanation: X holds the features; y holds the target — whether the connection is normal (0) or an attack (1).

🔀 Step 3: Train-Test Split

X_train, X_test, y_train, y_test = train_test_split(X, y, stratify=y, test_size=0.2)

Explanation: Data is split to evaluate model performance on unseen data. stratify=y ensures balanced class distribution.

🌲 Step 4: Train Random Forest

rf = RandomForestClassifier(n_estimators=100)
rf.fit(X_train, y_train)

Explanation: A Random Forest classifier is trained to predict threats. It combines multiple decision trees to reduce overfitting and improve accuracy.

📈 Step 5: Evaluate the Model

from sklearn.metrics import classification_report
y_pred = rf.predict(X_test)
print(classification_report(y_test, y_pred))

Explanation: Outputs precision, recall, and F1-score to assess how well the model detects threats and avoids false positives.

Sample Output:

              precision    recall  f1-score   support
           0       0.97      0.96      0.96     10000
           1       0.95      0.96      0.95      8000
    accuracy                           0.96     18000

Interpretation: High precision and recall show the model effectively identifies threats with minimal false alarms.

🧠 Step 6: SHAP Explanation

explainer = shap.TreeExplainer(rf)
shap.summary_plot(explainer.shap_values(X_test)[1], X_test)

Explanation: SHAP values reveal which features most influence the model's threat prediction decisions. This helps explain decisions and build trust.

🤖 Step 7: LSTM Neural Network

model = Sequential()
model.add(LSTM(64, input_shape=(X.shape[1], 1)))
model.add(Dense(1, activation='sigmoid'))

Explanation: LSTM learns from sequential data (e.g., time-series network traffic). The final Dense layer makes binary predictions using a sigmoid activation.
